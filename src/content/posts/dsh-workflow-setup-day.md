# 从零搭起一套 AI 工作流：DSH 深度折腾日记

今天把 DeepSeek Harness（以下简称 DSH）——一款"一切皆插件"的 AI 编码 Agent 框架——从"能聊天的工具"打磨成了"懂我的工作台"。从立规矩、接知识库，到装插件、踩坑修复，一整天下来收获很多，值得记一笔。

## 一、先立规矩：让 AI 记住"我是谁"

一天的开头，做的第一件事不是写代码，而是**立规矩**。

工作区根目录的 `AGENTS.md` 是每次会话自动加载的"全局记忆"。我们往里面写下了三条规则：

- **语言规则**：思考过程和回复一律简体中文；
- **目录规则**：新项目必须建独立文件夹，不散放文件；
- **知识库优先查询**：用户问任何问题，先查个人知识库 → 再查官方文档 → 最后才考虑其他途径。

紧接着，创建了一个更有野心的东西——**《全局复利与踩坑日志》**。这是一份跨会话的成长档案：每次新会话开始，AI 必须先读完这份日志，吸取历史教训；每次产生新经验，也必须追加进去。这样 AI 就真的能"越用越聪明"——今天踩过的 PowerShell 语法坑、搜索工具失效的替代方案、插件安装的完整流程，全都被记录在案，下次绝不重复踩。

## 二、接入知识库：AI 有了"第二大脑"

个人知识库是个 Markdown + MCP server 的轻量方案。做了一次全面体检：

- **隐私确认**：远程私有仓库确认为私有（未认证访问返回 404），笔记里也无密码/API Key，安全 ✅
- **git 整理**：6 个新笔记 + 2 个修改统一提交，工作区干净 ✅
- **接入 DSH**：挂载了 MCP 客户端，从此 AI 能直接调用 `search_knowledge`、`read_note`、`create_note` 等工具——问"我叫什么名字"不再是猜测，而是查库 ✅
- **编写规范**：给 README 补了笔记规范——主题英文短横线、文件名描述性、决策记录"结论+理由+日期" ✅

## 三、生态调研：该装什么，不该装什么

看到 GitHub 上有个很火的 `context-mode`（近 2 万 stars），认真评估了它。结论很明确：**在 DSH 上装了也没用**——它省 token 的核心机制依赖平台 hooks（PreToolUse/SessionStart 等），而 DSH 是 Cordis 插件架构，不在它支持的平台列表里；强行接入反而会因为工具 schema 常驻增加开销。DSH 自带的 spill 溢出存储 + 自动压缩已经覆盖了同样的问题。

顺手发现了 `dsh-plugin` 主题下 **1500+ 个仓库**的繁荣生态，以及一个自动扫描的"雷达站"（收录 288 个插件）。调研结论很实在：**生态很新很乱，大部分插件只有源码、没发 npm**，安装前必须逐个查包名和兼容性。

## 四、插件安装大作战

真正动手的环节。装了十几样东西，分成三条路线：

**npm 直装（最省心）**：

- `dsh-web-ui` 全家桶：任务看板、Git 图谱、右侧面板、桌面宠物、实时 token 统计、8 款皮肤（选了蓝鲸插画的 Blue Fantasy）——一个包装齐 11 个子包；
- `dsh-data-agent`：数据库工作台 + SQL 工具，AI 连上数据库写 SQL 还能看执行结果；
- `dsh-message-edit`：消息分支编辑、重试、版本时间线。

**手工挂载（源码没发 npm，但构建产物已提交）**：

- `dsh-vision`：给纯文本模型加视觉，看图工具转发给免费视觉模型（配置了 API Key，免费档偶发限流时自动降级备用模型）；
- `dsh-paste-input`：粘贴图片自动存进工作区附件目录；
- `distill`：后台反思对话、自动把可复用工作流蒸馏成技能；
- `dsh-memory-evolve`：五轨长期记忆 + 自我进化。

## 五、踩坑实录：三个硬仗

**① 字体太小**：桌面客户端（DSH 的 Electron 封装）的主进程文件居然**没打包压缩**，可以直接改代码。但更优雅的方案是——在通用设置插件里加了一个**字号设置行**（标准/大/特大），用 CSS zoom + 本地存储实现，UI 可控、重启保留。

**② 图片发不出去**：粘贴图片提示"模型不支持"。根因是宿主校验模型能力——当前模型声明不支持图片输入就拒绝。绕法不是骗过检查，而是用粘贴增强插件把图片**转成文件路径**发送——模型看到路径后调视觉工具分析，完整闭环。实测连发多张图全部成功。

**③ 会话恢复崩溃**：装某个插件后旧会话恢复报 `SessionFormatUnsupportedError`——它写入的自定义事件类型没注册进会话存储的事件注册表。修复方法：在注册表里补上这个事件类型，改了内置和用户两份副本，十几万条历史事件全部验证通过。

## 六、收尾：给博客动了个小手术

最后处理了自己的博客（Astro 构建）。从知识库查到完整信息并实测新旧两个地址都在线，然后按需求把两篇置顶文章取消置顶，提交推送，CI 自动构建。顺带修正了知识库里的分支记录——两个站点仓库分支不同，记下来免得下次推错。

## 写在最后

这一天最大的收获不是装了多少插件，而是建立了一套**可持续的工作方式**：

- 规则写进 `AGENTS.md`，每次会话自动生效；
- 经验写进踩坑日志，跨会话累积复利；
- 知识写进知识库，随时可查可写；
- 该装什么、不装什么，都有理有据地评估过。

DSH 说"Everything is a Plugin"，这一天的实践证明：**好用的工具不是装出来的，是一起打磨出来的。**
